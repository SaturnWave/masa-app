# masa-app

Masa uygulamasının (Okey ve 101 Okey; Android ve iOS) mağazaların istediği herkese açık sayfaları. GitHub Pages ile
yayımlanır:

- Gizlilik politikası: <https://saturnwave.github.io/masa-app/gizlilik.html>
- Destek: <https://saturnwave.github.io/masa-app/destek.html>

`gizlilik.html` ve `destek.html` elle düzenlenmez: uygulamanın deposundaki Markdown kaynaklarından
(`docs/yayin/gizlilik.md`, `docs/yayin/destek.md`) `tools/yayin_sayfalari.py` ile üretilir. Metin değişecekse kaynak
değişir, sayfalar yeniden üretilip buraya kopyalanır.

Public pages for the Masa app (privacy policy and support), generated from the app repository's sources.
